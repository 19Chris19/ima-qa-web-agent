## 已核对的证据

- 三次问答使用同一账号、同一知识库、同一上游 Session；整个窗口只创建一次上游 Session。
- 后两次请求未携带首轮核对标记，也未在请求文字中拼接前文；两次回答均正确复述标记。
- 第二轮后正常关闭独立 Provider 测试进程；新进程读取原任务／会话存储，核对上游历史后第三轮继续原 Session。
- 三轮各一个完成事件；流式正文、保存历史和任务 JSON 导出一致，早先轮次的历史前缀未改变。
- 模型与模式选择保留在每轮任务／历史中；完成后测试 profile 锁已释放。
- 计数：续期 1、模型目录 2、知识库目录 4（含一次明确目标库核对）、上游历史 2、会话创建 1、问答 3。未自动重试、重扫或追加提问。

前置预检因旧 profile 涉及两个成功知识库而停止，未发问；经用户明确指定知识库并批准回收本次孤立验收锁后继续。原失败记录保留；只清理了已核验的本次锁，没有清认证或未知问答保护标记。
