# Provider A 管理后台与账号维护

更新日期：2026-10-12。本说明区分后台已有能力、时间字段含义与部署维护通路；存在按钮不代表当前机器已准备好全部扫码／评测依赖。

## 后台在哪里，谁负责什么

Provider A 已有受管理员凭证保护的账号管理后台，默认本机入口为 `http://127.0.0.1:3117/admin.html`。服务部署在别的主机或端口时，以该安装的实际配置为准；`127.0.0.1` 始终指浏览器所在机器。远程维护通过经授权的 SSH 通道或专门受保护的管理网络，不使用普通问答中转入口，不直接将管理端口开放到公网。

管理员使用该安装私有配置中的管理员凭证登录。普通 API、网站业务凭证和 OpenAI 中转密钥不具备管理权限；不要让同事索要、共享或在聊天中提交管理员 token。打开管理页读取状态不会自动发起真实问答；检查、刷新、资格验证和重新登录是不同操作。

账号池、IMA 登录态、自动续期、知识库资格及扫码维护统一由 Provider A 管理。接入网站无需重复实现一套账号库或扫码逻辑。网站需要管理其业务用户、权限、配额或审计时，可以独立建设业务后台，但不能把 Provider 管理员凭证发送到网页或把业务身份当成账号维护权限。

## 时间字段怎么看

在账号列表或账号详情的“登录与维护”区域查看，布局以安装版本为准。时间来自服务端实际记录，按浏览器本地时区显示；跨设备协调须核对时区，例如北京时间为 `Asia/Shanghai / UTC+08:00`。缺失、未安排或上游未提供的时间应如实显示未知，不补造日期。

| 字段 | 用途与解释 |
| --- | --- |
| 上次检查 `lastCheckAt` | 最近一次认证巡检记录，不等于真实问答验证或成功续期 |
| 下次自动检查 `nextCheckAt` | 当前进程实际安排的检查时间；重启、停用或调度变化后可能改变 |
| 下次重试 `nextRetryAt` | 失败后实际安排的重试；正常情况下未安排不表示故障 |
| 可续期时间 `refreshEligibleAt` | 自动续期进入条件的参考时间，不是必须人工扫码时间 |
| 访问令牌到期 `tokenExpiresAt` | 短期访问令牌的上游到期信息；有有效续期凭证时通常可续期 |
| 续期凭证到期 `refreshTokenExpiresAt` | 较长期维护的参考；上游仍可能提前撤销，缺失时不能推算 |
| 上次成功续期 `lastSuccessfulRefreshAt` | 最近一次成功刷新登录凭证，不等于最后扫码登录时间 |
| 知识库验证时间 `knowledge.verifiedAt` | 已有知识问答资格证据的时间，与认证续期分开判断 |

认证巡检和自动续期不发送 IMA 问题。后台显示时间可帮助安排维护，但不存在一个可以保证的“所有账号在某天必须扫码”的日期。访问令牌到期不一定需要扫码；登录被拒绝、续期失败需人工处理、知识库权限变化等应结合明确错误与状态判断。网络故障或知识库资格未通过不能一概当成登录过期。

时间字段的合同见 [账号维护](ACCOUNT_MAINTENANCE.md)，界面及状态映射见 [管理体验](ADMIN_EXPERIENCE.md)。这些文档包含历史候选说明，不代表任意旧镜像或带补丁的迁移安装已经升级；应核对当前实际接口与运行代码。

## 如何组织一批账号的维护

1. 先只读查看知识库资格、可调度状态、维护时间和错误，区分正常、接近续期、等待重试及需要人工登录的账号。维护者可私下记录内部代号、负责人、时区和待办，不公开账号或凭证。
2. 正常账号按已有自动续期机制工作，不因短期访问令牌即将到期而批量要求重新扫码。记录较长期续期凭证的到期参考，并关注巡检是否按时成功；当前后台不等于已经具备离机告警或批量通知。
3. 需要重登录时，在维护窗口分批处理，先确认受影响账号的在途任务及续期者已按该版本维护合同安全收尾，保留其余可用容量。单击停用或看到 active 为零不代表所有后台续期已结束，不强删锁或并发操作同一身份。
4. 在 Provider A 使用“重新登录”等对应维护入口，由账号持有人在官方窗口扫码并确认知识库权限。保持原身份与会话绑定；身份冲突按 [重新登录身份处理](ACCOUNT_ENROLLMENT.md)明确处置，不用不同账号覆盖原记录。
5. 完成后分别核对保存结果、身份、登录状态、资格及可调度状态。需要真实 QA 时先说明并按授权执行；登录保存成功不能当作问答验收，也不能绕过待验证门禁。

不要用删除账号库或重新初始化来修复过期登录，也不要在另一台机器同时刷新同一组凭证。换主机遵守 [完整主机迁移](HOST_MIGRATION.md) 的停旧、单一运行端和最新状态回退要求。

## 2026-10-12 迁移环境的实际边界

接收端只读检查确认：本机管理页及管理员认证的账号查询可用，五个迁移账号均提供上述认证维护时间；当时没有待重试时间。固定运行界面具有对应时间字段及带时区格式化代码。没有为了检查而触发手工刷新、真实问答或扫码，也没有公开账号和具体时间。此记录不是完整管理 UI、五账号逐一问答或重新登录验收。

当前机器尚未准备新账号扫码浏览器，包内也缺少可选资格评测题库，新增资格评测不可用。已有资格与普通问答继续使用；后续安排人员扫码前必须先准备并单独验收维护通路，不能只把管理地址发给大家就承诺可重新登录。本轮文档更新不安装这些依赖，不更换固定运行代码，也不切换其他客户端。
