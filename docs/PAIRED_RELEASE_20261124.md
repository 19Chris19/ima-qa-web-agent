# Provider v0.8.0 与知天下 v0.6.0

本次版本接入固定 IMApy 协议核心、模型与快速／深度选择，以及账号池实时后台。
旧客户端、既有会话、账号资格和 Air Bot 调用继续使用已有契约。

已完成的限定真实验收覆盖同 Session 模型和模式切换、独立进程重启后追问、
联网证据与引用关联。两份生产可用账号的设备上下文均来自各自既有登录态，
按已核验账号身份匹配。正式池的小范围两轮问答在一个账号和同一会话中完成；
另一个账号通过目录读取，未将它记作真实问答通过。

设备信息与网页客户端身份均在服务机私有文件保存，不进入源码与安装包。
新内核按账号使用对应的网页身份，避免缺少新版客户端标识时上游返回旧模型目录。
旧账号凭证、资格、任务 JSONL 和历史不因升级重写。

本地 Provider 回归 1080 项通过、2 项长时钟测试跳过。Air 中继 19 项合成测试通过。
私网入口认证检查返回就绪。Air 端真实微信对话及手机真机体验保留为独立验收范围。

部署先关闭提交并排空，保存加密备份，再更新兼容后端与只读监控，
最后更新知天下、Vercel 及后台静态资源。切换后核对实际版本和资源摘要。
回退只恢复代码及配置，保留升级后产生的任务、会话和凭证。
新内核会话不能交由旧协议重新派发。
