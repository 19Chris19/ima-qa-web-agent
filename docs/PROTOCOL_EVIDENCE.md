# 问答来源与身份合同补强

本变更基于 #34 和固定稳定 main，保留私有材料映射与公开 chat_v1 投影的隔离。

## 来源与引用

CONTEXT_REFERENCES 的显式字典键仍是关联依据；字典来源同时进入来源列表与 citationMap。一键多页、重复页和迟到信息继续保留，不使用数组位置制造关联。列表与映射使用同一受限分类器；无来源类型和无已验证分类依据时保持 unknown。null、false、空串和数字字符串不会经类型强转成为网页来源。

上游规范化提供可选 onCitationDiagnostic 回调，只含阶段、固定类别及字段存在与否，不含引用键、材料 ID、正文或 URL。默认无回调、无落盘；调用方必须使用有界内存采样，不能在回调中同步写盘。已知来源事件分类为 missing_at_ingress 或 classification_unproved；客户端另报告冲突和投影保留情况。

## 网页证据

source-evidence-contract.js 是无副作用的检查器，客户端携带相同源码。verified 表示有明确网页映射或一致的终态网页计数；not_observed 表示终态明确为零；缺失、非法、相互矛盾的证据为 unverified。没有网页证据不改变答案状态，不追加第二次请求，也不能据此断言上游没有执行搜索。现有 Provider 终态和 BFF 界面不新增字段。

## 新安装命名身份

新安装在私有 installation-pending.json 内一次生成 ima-agent 的普通／内部凭据及独立 legacy／admin 凭据。该文件 0600，目录 0700；配置写入中断后使用原凭据恢复，成功后删除待完成日志，完成回执只保留身份元数据。普通与内部凭据通过 IMA_QA_APPLICATIONS_JSON 绑定同一应用，IMA_QA_AGENT_APPLICATION_ID 指示客户端默认选择。

已有安装和待恢复的旧版安装不自动迁移、不覆盖环境或历史；legacy 仍保留原所有权空间。命名身份不自动获得材料映射／读取授权。真实身份、权限与新机扫码验收另行进行。

## 验证边界
