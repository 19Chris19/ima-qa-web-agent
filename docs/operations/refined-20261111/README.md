# Provider A 后台精修本地候选

基线：`feced06`。分支：`codex/provider-admin-refined-20261110`。本地开发，不包含部署授权。

## 本地入口

- 后台：`http://127.0.0.1:4602/admin.html`
- 独立只读状态页：`http://127.0.0.1:4611/`
- 上一版后台 4601、独立状态页 4610 保留。

以上新版入口均为合成数据，不访问 IMA、生产账号库或生产问答。顶部场景选择仅在合成预览出现，可切换正常、容量下降、繁忙、入口故障、保存保护、未知和待验证资格。扫码不会生成真实二维码，维护按钮仅操作合成状态。

运行 `node scripts/operations/preview.js`。使用现有 Node 22 和依赖；不要将此预览脚本用于生产。独立部署监控使用 `scripts/operations/status-server.js`，与 Provider 分开运行，正式部署默认状态端口仍为 4610。新的 4611 只用于本次本地演示。

## 已实现

- 浅瓷灰、白色内容层、石墨文字；主状态暖琥珀 / 翡翠绿，故障红、繁忙蓝、未知灰。支持系统主题和手动主题。
- 首页固定为服务状态与计数、最近 10 分钟、待处理账号；容量依据和真实回答观测折叠。
- 日常主导航为实时概览、账号池；资格报告、并发演练和长诊断保留在高级工具中。
- 账号表格 / 手机卡片，筛选搜索，桌面右抽屉 / 手机底部面板。先展示登录、知识库资格、允许并发和依据；维护及完整记录折叠。
- 按状态给操作提示。所有维护继续走原接口及真实额度确认；服务端重新核对启用条件，不提供强制启用或任意脚本。保存不确定时可查看诊断，只有目录报告可核对才显示核对按钮。
- 独立监控每 5 秒采样，内存最多 120 点；前端 60 个十秒格，取格内最严重状态，显示缺失 / 部分覆盖。真实监控重启不从分钟历史补造细粒度记录。
- 原有 30 天分钟与变化历史保留，状态页中折叠展示；私网和网页封面仅作辅助详情，不决定主状态。
- 管理员同源只读 `/api/admin/operations/status` 固定读取本机状态地址，权限、超时、大小限制、短缓存及并发合并；客户端不能指定目标网址。状态字段使用嵌套允许列表。
- 最近窗口只在监控内存中更新，页面读取不触发账号库保存、问答、续期、扫码或资格验证。

“在线问答正常”表示入口健康检查通过，不代替真实回答质量与成功率。真实回答观测只统计已有任务，零样本不编造成功率。并发数字为当前允许派发问题数，不等于访客数，也不将试运行额度当作稳定并发实测。
