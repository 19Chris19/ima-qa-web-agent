# 账号持久化、维护统计与故障恢复

本改动是 v0.6.0 之后的候选可靠性修复，合并 PR 不等于现有安装已更新。Node 22 合成验收不替代真实扫码、问答或长期运行验收。

服务入口（包括 `server.js` 的 IMA 模式）统一使用 `AsyncAccountDirectory`。一个常驻 worker 串行执行账号事务：从当前磁盘状态建立独立副本，验证代际和摘要，提交成功后向 HTTP 进程发布不可修改的缓存。JSON 处理、加密、兼容导出和文件写入留在 worker；HTTP 不同步等待子进程。同步 `WebAgentAccountDirectory` 核心保留给 worker 和离线工具，不作为 HTTP 服务目录。

关键事务覆盖凭证、启停、资格、健康检查、冷却/错误隔离及配置。文件和父目录刷盘、原子替换、0600、短期 CAS 写锁及进程生命周期 fence 均保留；异步文件 I/O 让 worker 的写锁续期在慢盘期间仍可执行。关键操作最多一个执行、64 个等待；超额拒绝，不形成无限队列。20 秒是提交保护期限，不是承诺磁盘耗时。

管理路由、扫码捕获、手动与自动刷新、资格评测、迁移兼容回调均等待事务结果。待保存的凭证不参与新派发，重新扫码替换期间保持隔离；旧刷新不能覆盖新登录态。兼容明文导出如仍配置，也在 worker 中完成；它失败时不能假称整个刷新成功。

使用次数和最近使用时间保存到账号库旁的 `<store>.runtime-stats.json`（0600），按原身份指纹关联，每 1 秒最多合并一次自动保存。活动请求数仅在内存，启动不恢复旧活动 lease。统计不改变凭证库代际和资格绑定；空闲维护若没有实际变化，不产生账号库提交。1 秒是正常调度间隔：磁盘故障或关键事务拥塞可能扩大统计丢失窗口，过期/失败通过健康字段和限次状态变化日志告警。

`/healthz` 增加可选 `persistence`：`ready`、`statisticsReady`、`pendingWrites` 和 `writing`。存储故障使执行容量归零，但健康 HTTP、已在途的流、读取和取消通路继续可响应；不以存储失败推断账号掉线。任务日志仍使用现有 JSONL v2，不改变机器人问答合同。

超时、worker 崩溃、代际冲突或无效存储后，不自动重放修改或 IMA 请求。管理员可调用认证后的 POST `/api/admin/persistence/reconcile`，无请求参数；它在写锁下核对本次修改前/后的摘要，重新确认持久性，必要时修复已提交凭证的兼容导出，再返回 `committed` 或 `not_committed`。无法匹配、文件损坏或仍被锁定时继续拒绝新派发，安排人工维护；不能用空账号池或旧备份强行恢复。旧回执不会更新另一次事务。

备份须在关闭入口、任务排空及停止单写入者之后制作，保留加密账号库、原密钥、统计快照、任务 JSONL/检查点、会话历史、网站归属、待发记录及 Cookie 签名。正常停机先刷新统计，再将最新计数合并回旧代码可读的账号库；不恢复旧活动请求数。若曾非正常退出，旧代码回滚前在离线窗口运行：

```sh
node scripts/finalize-account-statistics.cjs --store /ABS/PRIVATE/accounts.json --key /ABS/PRIVATE/accounts.key --confirm-offline
```

工具要求既有私有文件，并取得同一生命周期 fence；服务未停时拒绝。不创建密钥，不启动账号池，不调用 IMA。回退必须保留 JSONL v2 读取能力，不能覆盖新历史。Mac 调度与网站实时排空检查需要配套更新，见知天下的维护说明及 `deploy/macos` 工具。

可复现性能对照：`node scripts/bench-account-persistence.cjs /PRIVATE/OR/REDACTED/report.json`。使用独立临时合成账号、随机 loopback 端口和固定 SSE；冻结 v0.6.0 同步实现只存在于脚本夹具，不供服务导入。结果不代表真实 IMA 耗时；真实重建负载及生产切换另行授权。
