# 已有 Provider 服务的完整主机迁移

更新日期：2026-10-12。适用于同一维护者经授权迁移自己的既有服务；新用户安装仍走 [Agent 部署](AGENT_DEPLOYMENT.md)。不向其他部署者分发维护者的账号、密钥或历史。

## 已验证的实践与适用范围

一次 macOS → Apple Silicon macOS 的完整迁移已保留既有加密账号池、解密密钥、服务凭证、会话归属、历史与持久任务。使用固定迁移代码和 Node 22，恢复后无需逐账号重新扫码，实际首问、同会话追问及完整网站公网链路问答均通过。普通问答运行不依赖保留扫码浏览器窗口。

这证明已有有效登录态可以随完整私有状态迁移，不是跨系统或永久免扫码保证。IMA 登录过期、网络变化、权限变化或上游风控都可能要求重新登录。Linux、云服务器、Windows、全新账号扫码、逐账号真实问答和长期运行需另验。账号可调度数量也不等于每个账号均通过真实问答。

此次恢复依据专门制作的固定包及其清单，包括原部署兼容补丁；没有用公开 main 或空池安装替换。接收端的托管、中转与网络辅助工具是单独的运行配置，不因此成为本仓库稳定 Release 的功能。

## 完整迁移与账号追加导入不同

[离线账号迁移工具](ACCOUNT_TRANSFER.md)解决已有两个安装间的受控账号追加、去重及停用待验证导入。它不提供整台主机、网站签名、访客历史或公网切换的自动恢复；其待验证门禁和退役要求继续有效。

完整主机迁移恢复同一个安装的完整状态与原密钥。不能将这种结果解释成可以绕过账号追加导入门禁，也不能把旧 runtime 覆盖到另一套正在使用的安装。目标有独立账号或数据时先评审合并方案，不覆盖。

## 必须作为一组保留的内容

| 内容 | 为什么要保留 |
| --- | --- |
| 固定源码、锁文件、版本与补丁清单 | 保持账号存储、任务合同和机器人扩展兼容 |
| 加密账号库及对应解密密钥 | 仅有账号 JSON 无法恢复登录态；密钥不能重新生成 |
| 私有环境、应用凭证和应用身份 | 后端鉴权及会话命名空间保持一致 |
| Provider 会话、账号／上游绑定、持久任务和回执 | 保持追问、历史归属与已提交任务身份 |
| 调度、资格、维护状态及所有配置的数据路径 | 不只备份三个默认文件；按实际配置和清单收集 |
| 配套网站的签名、归属、队列和任务恢复记录 | 网站独立保存；只恢复 Provider 不足以保留网页体验 |

路径及文件名以实际私有配置和迁移清单为准，不在公开文档列出运行数据或真实身份。保留绝对路径的映射记录，校验后改到接收端私有目录；不能猜测丢失字段、删除未知锁或重新初始化修复。

## 操作顺序

1. 盘点固定代码、补丁、Node 22 依赖、所有数据和密钥路径、进程托管及接入入口。记录脱敏计数和验证项目；不要把账号、凭证、私有映射、日志及历史放入 Git。
2. 关闭新任务准入，处理并排空在途任务和待发队列；已派发的 IMA 生成不能因复制任务文件而承诺续跑。保留失败／不确定记录，不自动重新提问。
3. 停止旧 Provider、配套网站、入口及其他写入／续期者，并停用其自动重启。由旧端确认停用状态。相同账号不能在两台主机同时刷新和派发，端口不监听本身也不能证明所有续期者已停止。
4. 从最终停止状态制作完整快照，附全部文件摘要和固定代码信息，使用接收端 age 公钥加密。身份文件只留接收端私有目录；用 `age-keygen -y` 导出公钥，不展示私钥全文。经可信通道传送并核对密文 SHA-256，避免源端停止前的旧包被当作最终状态。
5. 在新建的私有目录解密。目录 0700、私有文件 0600，不放 Git、共享或云同步目录。解包前拒绝绝对路径、路径穿越、符号／硬链接、设备文件和冲突成员，限制大小；解包后校验清单中所有成员、摘要和预期文件集合，不执行包中未知安装脚本。
6. 阅读包内迁移说明并与维护者授权核对。准备目标架构的 Node 22 与锁定依赖；不要照搬旧系统的二进制或 `node_modules`。更新明确的数据路径和托管配置，验证解密、原账号记录、历史归属和任务记录；不执行 `setup`、`onboard init`、空池初始化或浮动源码升级。
7. 报告拟启动目录、端口和入口，取得停旧已确认的切换授权后再启动。启动本身可能续期，不能先启动后补授权。先验证鉴权、合同、容量及历史，再按授权发少量非隐私真实首问和追问。
8. 公网入口、其他客户端和机器人分别验收；先确认客户端原应用身份、访客标识、幂等键和任务恢复语义。公网只暴露必要路由，管理／内部接口保持封锁。切换后保持旧续期／派发端停用。

接收端解包、摘要检查、路径改写和启动辅助需经实际环境审查。本说明不是现成的一键迁移命令，也不保证稳定 Release 自带该自动化。

## 复核与回退

分别记录：文件完整性、密钥可用性、账号计数、原历史与归属保持、容量、真实问答、唯一终态和任务恢复。只输出计数、状态及耗时，不输出真实问答、来源、账号或会话 ID。

新端启用后可能已经刷新凭证并写入新会话。回退必须先停止新端所有续期和派发者，再审查最新状态与旧代码兼容性；不得直接启用旧包、回写过期凭证或覆盖切换后的新任务。应保留原密文、不可变快照及新的加密一致性备份，并在独立隔离环境演练恢复。

## 正式服务器仍需验收

- 目标 OS／架构、固定依赖、文件权限、持久存储与写锁语义；扫码维护通路和资格评测依赖。
- 无人值守托管、重启和断电恢复；macOS 登录启动不能等同于 Linux 系统服务或开机未登录即可运行。
- 网络／证书、远端 DNS、SSE、幂等、访问隔离和密钥撤销；不关闭 TLS 校验求通过。
- 账号登录及续期、逐账号真实问答、并发／限流、数日运行、离机告警、最新加密备份与完整灾难恢复。

迁移与真实问答证据只覆盖记录中的环境和场景；未知提交、源端退役和其他平台能力不能由健康检查推断。
