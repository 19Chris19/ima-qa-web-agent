Stable durable-task release of the reviewed v0.5.0-rc.1 implementation. This
promotion changes version/default-image and current deployment documentation,
not executor, account or UI code. Pair private website v0.3.0 with this version.
The v0.5.0 preparation tag remains immutable and was not published as Latest;

## Install and verify
Use this complete source tag (with lockfile) or the attached immutable public
ARM64/AMD64 image manifest; read README and docs/AGENT_DEPLOYMENT.md. Node and
Docker are two installation paths for the same release. Human QR login, phone
confirmation and knowledge-base membership remain necessary. Website source and
image are private and not included in this repository.

Full synthetic CI, npm packaging, native ARM64/AMD64 image startup and public
anonymous image access are release gates. Local code regression: 822 pass,
6 optional skip, no failures; clean npm ci reports zero audit findings. Final
CI and image evidence is attached to Release. No fresh real IMA question was
sent; earlier Air real long-answer/follow-up evidence is not a new image test.
Windows desktop, SSH enrollment, new-account full login/QA and real Linux long
uptime remain unverified. Air host/tunnel readiness is a separate operational
problem; stable code selection is not a 24-hour availability guarantee.

## Upgrade and rollback
Stop admission, drain active and queued tasks, back up current private data and
configuration, verify robot/custom extension compatibility, then switch one
writer to the fixed artifact. Keep encryption/signing keys, accounts, histories
and task logs; never reinitialize existing data. Publication does not restart
Air services, Docker Provider or robots.

Rollback only to compatible task-aware code after draining, never by overwriting
new data with old backups or automatically re-asking dispatched uncertain tasks.
Fresh real first-question/follow-up acceptance requires separate authorization.
