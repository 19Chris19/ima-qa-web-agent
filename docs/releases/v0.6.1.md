# Provider A v0.6.1

配套稳定补丁：Provider v0.6.1 / 知天下 v0.4.1。前端问答功能与 JSONL v2 任务合同保持兼容。

账号关键事务改由常驻异步 worker 持久化，保留单写者、CAS、刷盘和凭证隔离；统计每秒合并保存，慢写不冻结 HTTP，未知提交结果停止派发并通过管理员核对。支持离线统计回滚合并。

验证：Node 22 合成回归、保存故障和排空测试通过；20 秒慢写测量健康 P95 约 2.23ms，额外 RSS 峰值约 41.5MiB。镜像必须等两架构启动检查和 release-manifest.json 附件完成才视为发布制品验收。详见可靠性验收报告。

现有安装先关闭入口、排空、停止单写者并制作已验证的加密备份；保留账号登录态、密钥、历史及本机兼容补丁，Provider、网站和宿主工具配套更新。统计可能在异常退出时丢失末尾约一秒；回退前按 Provider 的 docs/ACCOUNT_PERSISTENCE.md 合并最新统计，不能覆盖上线后的历史。
