# v0.3.0 开发验收记录

当前为本地开发分支，不是可部署的正式版本。公开项目仍优先服务网页问答和 iframe 嵌入，机器人示例属于后续章节。

## 已接入的流程

- 新账号库默认选择 `knowledge_agent`，已有账号库未记录模式时保留 `classic_knowledge`。
- 管理页可显式升级新会话；历史会话保存自己的模式，不随全局模式切换。
- 扫码接入前显示真实问答验证提示，可填写知识库相关问题。浏览器关闭后只运行一次验证；失败保留账号，不写客户会话或发送机器人消息。
- 只有一次派发、一个成功终态、非空回答及目标知识库来源的证明才能授予默认原生模式资格。
- 账号库更新使用版本比较，拒绝旧快照覆盖。首次迁移前在私有目录生成备份。
- 管理端能查看基础健康、待验证、可调度数量，并手动重新验证。
- 内部容量接口和终端适配器已初步接入；示例说明见 `examples/bot-adapter/README.md`。

## 不得跳过的发布门槛

1. 完成跨进程锁崩溃、陈旧回收锁、并发写入与重启恢复测试。
2. 完成服务端持久幂等和不确定完成态处理。当前示例去重只在进程内有效。
3. 完成新接入、取消、重新登录、模式升级及容量变化的浏览器验收。
4. 使用隔离账号做真实 IMA 验收，记录脱敏计数，不记录问题、答案、身份或来源原文。
5. 完成干净安装、打包、旧版升级和回退演练，以及至少 30 分钟完整请求链路模拟运行。
6. 补齐公开说明、合成案例截图和中文更新日志后，才准备发布 PR。

## 升级与回退原则

先备份私有账号库、密钥和会话数据，再在隔离目录验证；不允许两个版本共写一个账号库。新格式账号库不能直接交给旧进程写入。回退必须停掉新进程并恢复成对的旧库及密钥备份。任何自动回退都不得覆盖更新后的凭据。

本次未重启 3117、未修改微信 QA Bot 部署、未推送 GitHub 或创建 Release。
