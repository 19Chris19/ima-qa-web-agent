# Provider A v0.3.0 发布与验收记录

本记录说明 Provider A v0.3.0 的发布内容与验收边界。公开项目仍优先服务网页问答和 iframe 嵌入，机器人示例属于二次开发参考。真实 IMA 验收步骤由部署者在独立环境中使用自己获授权的账号完成，具体见 `docs/ACCEPTANCE_TESTING.md`。

## 已接入的流程

- 新账号库默认选择 `knowledge_agent`，已有账号库未记录模式时保留 `classic_knowledge`。
- 管理页可显式升级新会话；历史会话保存自己的模式，不随全局模式切换。
- 接入表单先收集知识库测试问题；扫码登录成功后，服务自动运行一次隔离的真实问答验证。失败保留账号但不授予调度资格，账号行提供手动重试入口；探针不写客户会话或发送机器人消息。
- 只有一次派发、一个成功终态、非空回答及目标知识库来源的证明才能授予默认原生模式资格。
- 账号库更新使用版本比较，拒绝旧快照覆盖。首次迁移前在私有目录生成备份。
- 管理端能查看基础健康、待验证、可调度数量，并手动重新验证。
- 内部容量接口和终端适配器已初步接入；示例说明见 `examples/bot-adapter/README.md`。

## 当前本地验证

- 账号目录使用 generation CAS 和跨进程文件锁；覆盖陈旧 generation、双进程竞争、迁移私密备份以及杀死锁持有进程后的锁恢复。容量摘要检查运行池已应用的 generation。
- 内部 JSON 深查支持七天持久幂等回执；回执仅存身份/请求/答案哈希、状态及会话定位。已完成结果从所属会话恢复；重启时发现仍 processing 的回执会改为 unknown 并拒绝重发。
- 集成测试覆盖相同消息并发只派发一次、不同请求复用同一键被拒绝、成功重启重放、失败/不确定状态重启后不重发。另修正请求体读取完成时 `IncomingMessage.destroyed` 被误当作客户端断开的竞态。
- Provider A 全量测试通过 `233/233`；从白名单 npm tarball 的干净安装环境再次通过 `233/233`。
- 主网页、嵌入页和管理页做过 1280px / 390px 的合成浏览器验收；这不是扫码登录或真实上游验收。
- `npm run soak:synthetic` 已完成 30 分钟生命周期演练：8 位合成用户共完成 9,127 次问答和 536 次幂等重放；200 次慢请求超时、152 次取消及 4 次排队超时均未引发重派。失败 0、跨用户串话 0、峰值活动请求 4/4，结束时活动请求和排队数均为 0。该数据只证明本地合成链路，不代表真实 IMA 容量。
- 独立临时目录干净 `npm ci` 安装 80 个依赖成功；npm 包共 109 个白名单文件，未包含 `.env` 实值、`runtime/`、账号凭据或真实会话。抽取发布包后再执行干净安装和全量测试通过。
- 使用合成账号库完成 `0.2.2 -> 0.3.0-rc.0` 隔离升级和配套回退演练；账号目录、凭据字段和会话可由升级版读取，回退按私密备份恢复，没有让新旧进程同时写库。
- README 已有网页/嵌入/管理界面合成图；机器人终端示例与接口契约已写入 README 和 `docs/BOT_ADAPTER.md`。示例不连接微信或 Android。

## 社区验收边界

本地合成测试、30 分钟 soak、npm 包检查和隔离升级回退已验证代码逻辑，但没有真实 IMA 账号时不能证明扫码、目标共享库权限、真实来源召回或上游容量。当前维护者没有可供隔离测试的账号，因此本版本不宣称完成真实上游验收。

下载者应在各自的隔离环境中按 `docs/ACCEPTANCE_TESTING.md` 完成单账号接入、自动问答资格验证、来源检查、连续追问和重启恢复；自动验证失败时再使用手动重试入口。至少有两个独立授权账号后，才运行真实并发演练。合成测试不替代这些步骤。

源码清单、锁文件和中文更新日志均以 `0.3.0` 为版本号。自动化验证不等于真实 IMA 上游验收：维护者没有隔离的授权账号，因此不宣称扫码、目标共享库来源质量或真实容量已经通过。部署者应依照验收指南完成自己的真实环境检查；GitHub Release 与标签状态以仓库 Releases 页面为准。

## 升级与回退原则

先备份私有账号库、密钥和会话数据，再在隔离目录验证；不允许两个版本共写一个账号库。新格式账号库不能直接交给旧进程写入。回退必须停掉新进程并恢复成对的旧库及密钥备份。任何自动回退都不得覆盖更新后的凭据。

本次验证不重启 3117、不修改微信 QA Bot 部署，也不使用其他部署者的真实 IMA 账号。GitHub Release 和标签状态以仓库 Releases 页面为准。
