# v0.6.2 手机引用与输入栏修复

固定配套：知天下 v0.4.2。本版纳入 Provider #31 的触屏来源准确性修复和手机输入栏留白，不改变问答接口、账号池、JSONL v2、凭证或机器人合同。

网页角标实际占用独立的 44×44px 触控区域，首次点按只打开对应来源的底部面板；点击面板卡片才访问网页。蓝色网页角标与绿色不可点击知识库角标继续区分。手机输入栏底部至少留白 32px，或高于系统安全区 8px；保留草稿和回答末尾的滚动空间，桌面交互保持兼容。

自动化验收使用 Node 22 与原生 Chromium CDP 触屏事件，覆盖五种视口、相邻/换行/表格/一对多来源、目标边缘、草稿、桌面链接和短视口布局。真机 iOS Safari/Android Chrome 的安全区、浏览器工具栏和软键盘仍未验收，不能将浏览器模拟视为真机通过。本次发布不追加真实 IMA 问答或扫码。镜像需两架构启动检查和 release-manifest.json 完成后才视为制品验证通过。

已有安装先关闭入口、验证排空、停止单写者，制作并验证加密备份，再按固定发布提交更新。保留现有账号、密钥、Cookie 签名、会话与任务记录及迁移兼容文件。回退仅恢复旧代码与对应版本标记，不能用旧数据覆盖新增历史。Air 机器人不在本版变更范围。
