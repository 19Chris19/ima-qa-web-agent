# v0.6.3 问答失败恢复与悬浮交互

固定配套：知天下 v0.4.3。本版纳入 Provider #38；已合入的 README 与部署说明更新保留。

明确失败或停止的回答提供“重试”，成功回答提供“再问一次”。先读取原任务验证归属和终态，再由用户显式提交新轮次；保留旧失败、草稿与联网意图。状态未知、回执丢失或断线时只恢复同一请求，不自动新建问答。失败后暂停的待发问题仍须用户处理。

输入框外层透明，保留已确认的手机 32px 留白与安全区；正文可以从悬浮框周围滚过。返回最新箭头按实际距离和阅读意图显隐，支持键盘、减少动态效果与中途打断。知天下刷新历史直接定位输入框，不让入场动效挡住重试；终态计时使用记录中的 terminalAt。

测试使用 Node 22、合成任务与原生 Chromium 触屏，覆盖重试单次提交、草稿和旧失败保留、未知请求恢复、引用命中和阅读空间。镜像在 amd64/arm64 启动验收并生成清单后才视为制品通过。真机软键盘及更新后真实 IMA 问答仍需独立授权验收，不以合成或健康检查替代。

已有安装先关闭入口、验证排空、停止单写者，制作并验证加密备份，再按固定发布提交更新。保留账号登录态、密钥、Cookie 签名、会话、任务及迁移兼容文件。数据格式仍为 JSONL v2，依赖不变；回退仅恢复旧代码与对应版本标记，不用旧数据覆盖新增历史。Air 机器人、MCP 与原文读取不在本版变更范围。
