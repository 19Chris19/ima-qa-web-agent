# v0.7.0 可配置弹性账号调度

固定配套：知天下 v0.5.0。新调度默认关闭，不自动提升既有账号的执行额度。

同一账号的独立会话可以按额度并行，同一会话继续串行。每个账号默认至少间隔
3 秒发起一次；上游拥塞时缩小执行窗口、延长间隔并暂停新增派发，不取消已开始
回答、不自动重试，也不迁移已有会话。账号、登录主体、模式与模型必须匹配私有
验收记录；未匹配范围维持一路。应用预算与网站访客限流是另外的有界保护。

可另行显式配置最高五路的 operator_trial，准确绑定账号、登录主体、模式和模型。
该配置不写入验收记录、不声明逐账号/模式通过；关闭或删除即可回退为一路。

2026-10-19 仅在一个官方网页账号、快速 official_3 模式上观察到五个已有会话
同时输出，错峰一轮五问成功。此前集中发送一轮曾出现两次提问过快。这不是
所有账号或知识库模式的验收，3 秒不是官方频率承诺。20/100 仅为本地可配置上限。

两仓实际代码的联合合成检查覆盖共享额度、排队取消、断线原任务恢复、同会话
追问、BFF 重启及跨应用隔离。合成测试与无凭据镜像启动不能替代真实问答容量验收。

受控更新先关闭入口、验证排空，私有加密备份后停止唯一写入实例，只覆盖已核对
基线的代码增量。保留账号密钥、登录态、Cookie 签名、会话、任务与迁移兼容代码。
回滚先关闭弹性与应用预算开关；需要回退代码时不恢复旧数据覆盖新增历史。
Air 机器人、模型切换、知识库原文读取不在本版启用范围。
