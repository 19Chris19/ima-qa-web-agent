# 研究与教程

先把用户主题拆为少量明确问题，例如 3DGS Hub 条目的适用场景、操作步骤、参数依据、常见失败和版本差异。逐个提问，复用会话追问歧义，不要假设一次回答覆盖全部库。

每个终态任务及时导出；来源证据与撰写内容分开保存。条目建议包含标题、适用版本、前置条件、步骤、注意事项、来源、待核实项。保留来源链接、citationMap 与任务 ID；没有网页链接的引用保留其真实标识，别生成虚构 URL。

明确区分 IMA 回答、上游引用片段、实际读到的原文和自己的归纳。需要核实关键结论时，在用户授权范围内按[原文证据核验](source-verification.md)读取明确关联的材料，不默认下载全部引用。证据不足时标注缺口；后续追问遵守当前授权。完成研究后按用户网站已有内容格式生成草稿；发布前检查来源可公开性及用户给定范围。此 Skill 不会自动发布站点。
